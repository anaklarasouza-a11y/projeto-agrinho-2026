# 📖 Sobre o Projeto

O projeto **Agrinho 2026** foi desenvolvido com o objetivo de demonstrar a importância da união entre o campo e a cidade, valorizando a sustentabilidade, a inovação tecnológica e a preservação ambiental.

Através deste site, buscamos conscientizar a sociedade sobre o papel fundamental da agricultura no desenvolvimento econômico, social e ambiental do Brasil.

---

# 🎯 Objetivos

✅ Promover a educação ambiental.

✅ Incentivar práticas agrícolas sustentáveis.

✅ Demonstrar a importância do agronegócio.

✅ Valorizar o produtor rural.

✅ Apresentar tecnologias inovadoras para o campo.

✅ Fortalecer a conexão entre campo e cidade.

---

# 🌎 Tema Agrinho 2026

## Agro Forte, Futuro Sustentável

O tema destaca a necessidade de equilibrar a produção agrícola com a preservação dos recursos naturais, garantindo qualidade de vida para as futuras gerações.
